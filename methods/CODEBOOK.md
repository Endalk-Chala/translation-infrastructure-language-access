# Codebook

## Core fields
- `item_id`: stable item identifier
- `english`: English institutional source
- `amharic_official`: official Amharic institutional reference
- `oromo_official`: official Afaan Oromo institutional reference
- `meta_amharic`: Meta SeamlessM4T v2 Amharic output
- `meta_oromo`: Meta SeamlessM4T v2 Afaan Oromo output
- `google_amharic`: Google Translate Amharic output
- `google_oromo`: Google Translate Afaan Oromo output

## Evaluation fields
- `semantic_score`
- `pragmatic_score`
- `institutional_score`
- `actionability_score`
- `error_type`
- `review_notes`

## Development status
Rows are development items until native-speaker review/adjudication is complete.
